CRDb Cinema Platform — ملفات المصدر

محتويات الحزمة:
- واجهة الموقع React/Vite داخل artifacts/crdb
- خادم API الذي يجلب بيانات TMDB بأمان داخل artifacts/api-server
- المكتبات المشتركة ومواصفات API
- إعدادات pnpm وملفات المشروع اللازمة للتشغيل

التشغيل محلياً:
1) فك الضغط ثم شغّل: pnpm install
2) أضف TMDB_API_KEY إلى متغيرات البيئة الآمنة على الخادم. لا تضع المفتاح في ملفات الواجهة أو ترفعه إلى Git.
3) في نافذة طرفية أولى: pnpm --filter @workspace/api-server run dev
4) في نافذة طرفية ثانية: pnpm --filter @workspace/crdb run dev
5) افتح رابط Vite الذي يظهر في الطرفية.

في Replit، أضف TMDB_API_KEY عبر Secrets وشغّل الـworkflow الخاص بخادم API والـworkflow الخاص بالموقع.

ملاحظة: هذه نسخة الاستكشاف والكتالوج. تسجيل الحسابات والقوائم والمراجعات الدائمة غير موجودة في هذه الحزمة.
